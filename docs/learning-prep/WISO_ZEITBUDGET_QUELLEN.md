## Eigenständige didaktische Ableitungen

Eine Budgetgleichung `Bearbeitungsbudget = Gesamtdauer − Orientierung − Kontrolle` ist eine eigene Planungsdarstellung, keine Vorschrift der Quellen. Selbst erfundene Minutenwerte, Zwischenmarken, Restzeitfälle und Übungsaufgaben werden ausdrücklich als Beispiel gekennzeichnet. Ein Quotient aus verbleibender Zeit und Aufgabenanzahl ist nur ein grober Durchschnitt, keine starre Frist pro Aufgabe: Umfang, Punkte, Schwierigkeit und aktueller Fortschritt können unterschiedlich sein.

Weder Q1 noch Q2/Q3 belegen „immer eine Minute pro Frage“, eine fest vorgeschriebene Anzahl von WiSo-Aufgaben, eine universelle Zeitteilung oder eine Erfolgsgarantie. Ein eigener Plan kann während der Prüfung anhand der Restzeit angepasst werden; die Reserve sollte nicht beiläufig vollständig für eine festgefahrene Aufgabe verbraucht werden. Das ist eine didaktische Strategie, keine neue IHK-Regel.

Keine Originalaufgaben oder Buchpassagen werden reproduziert. Die Recherche belegt Dauer und begrenzte Lernstrategien; konkrete Fälle, Zahlen und Feedback entstehen eigenständig.
