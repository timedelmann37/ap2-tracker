Kapselung, PDU und MTU sicher anwenden

Prüfungsrelevanz: hoch ≈ 22 Min. noch offen Pilot · fachlich in Prüfung

Kapselung bedeutet im Netzwerk nicht, dass Daten mehrfach inhaltlich kopiert werden. Jede Schicht ergänzt die Steuerinformationen, die sie für ihre eigene Aufgabe benötigt. Die MTU setzt dabei eine Grenze für die Größe des IP-Pakets auf einem konkreten Übertragungsabschnitt.

Nach dieser Einheit kannst du …

  • Anwendungsdaten beim Senden und Empfangen den PDU-Stufen Segment oder Datagramm, Paket, Frame und Bits korrekt zuordnen
  • aus MTU und Headergrößen die maximal verbleibende Transportnutzlast berechnen und MTU-Fehler fachlich einordnen

1Einstieg: Welche Hülle sieht der Switch?

Ein Ethernet-Switch entscheidet, an welchen lokalen Port er eine empfangene PDU weiterleitet. Welche Hülle wertet er für diese Kernaufgabe aus?

Leserichtung

Beim Senden werden Header von oben nach unten ergänzt. Beim Empfangen werden die Hüllen von unten nach oben geprüft und entfernt.

2PDU-Namen als Funktionsmodell

Eine Protocol Data Unit ist die Dateneinheit einer bestimmten Schicht. Sie besteht aus der Nutzlast dieser Schicht und ihren Steuerinformationen. Was oben noch eine vollständige Transport-PDU ist, wird für IP zur Nutzlast. Das IP-Paket wird wiederum zur Nutzlast des Ethernet-Frames.

Sprachfalle

Im Alltag wird oft jedes übertragene Objekt „Paket“ genannt. In einer Prüfungsbegründung ist IP-Paket präziser; auf der Sicherungsschicht heißt die PDU Frame.

3Durchgerechnetes Szenario: Passt die TCP-Nutzlast?

Ein Ethernet-Abschnitt verwendet eine MTU von 1500 Byte. Gesendet wird IPv4 mit einem 20-Byte-Header und TCP mit einem 20-Byte-Header; Optionen und zusätzliche Tunnel fehlen. Die MTU begrenzt hier das vollständige IP-Paket. Ethernet-Header und -Trailer werden nicht von diesen 1500 Byte abgezogen.

1500 B−20 B IPv4−20 B TCP=1460 B Nutzlast
1500 B MTU des IP-Pakets20 B IPv4 ohne Optionen20 B TCP ohne Optionen1460 B maximale Anwendungsnutzlast

Eine Anwendung, die 1460 Byte TCP-Nutzlast liefert, passt in diesem vereinfachten Fall in ein IP-Paket. Bei 1461 Byte wäre das Größenbudget überschritten. Je nach Protokoll, gesetzten Flags und Pfad wird dann segmentiert, fragmentiert oder das Paket verworfen. In der Praxis soll Path MTU Discovery eine passende Paketgröße entlang des gesamten Pfads ermitteln.

4Geführte Übung: Hüllen in Sendereihenfolge

Ordne zuerst ohne Nachschlagen. Frage dich bei jedem Schritt: Welche Schicht erhält die PDU von oben und welche eigenen Steuerinformationen ergänzt sie?

Vom Browser bis auf das Kabel

Bringe die fünf Schritte in die Reihenfolge, in der sie beim Sender entstehen.

Übung
  1. 1Der IP-Paketinhalt wird in einen Ethernet-Frame für den nächsten Link gekapselt.
  2. 2Die Anwendung erzeugt die fachlichen Nutzdaten.
  3. 3Der Frame wird als codierte Bits beziehungsweise Signale übertragen.
  4. 4Das TCP-Segment wird mit einem IP-Header zum IP-Paket.
  5. 5TCP ergänzt seinen Header und erzeugt ein Segment.

5MTU-Fehler erkennen

Die MTU gehört zu einem konkreten Link beziehungsweise Pfadabschnitt. Ein Tunnel fügt weitere Header hinzu und kann dadurch die effektive Nutzlast senken. Unterschiedliche MTUs entlang des Pfads werden problematisch, wenn zu große Pakete nicht passend verkleinert werden können oder notwendige Rückmeldungen gefiltert sind.

Eine saubere Analyse trennt deshalb drei Fragen:

  1. Wie groß ist die MTU des engsten Pfadabschnitts?
  2. Welche Netzwerk- und Transportheader liegen tatsächlich vor?
  3. Welche zusätzlichen Tunnel-, Sicherheits- oder Protokollinformationen werden ergänzt?

Nach dem Aufbau eines VPN funktionieren kleine Anfragen, große Übertragungen bleiben jedoch hängen. Welche Hypothese prüfst du zuerst?

0 Zeichen notiert
Muster: Die Anwendung liefert Daten. TCP oder UDP ergänzt einen Transportheader; IP ergänzt logische Adressen; Ethernet ergänzt die lokale Link-Hülle; anschließend werden Bits beziehungsweise Signale übertragen. Bei 1500 Byte MTU benötigen IP- und Transportheader einen Teil des Budgets, sodass weniger Platz für Anwendungsdaten bleibt.
