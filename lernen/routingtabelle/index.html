Routingtabellen sicher lesen

Prüfungsrelevanz: hoch ≈ 21 Min. noch offen Pilot · fachlich in Prüfung

Eine Routingtabelle ist keine Liste kompletter Ende-zu-Ende-Wege. Jede Zeile beantwortet nur den nächsten Schritt: Für welchen Zielbereich gilt der Eintrag, über welches Interface verlässt das Paket den Router und muss es zuvor an einen weiteren Router übergeben werden?

Nach dieser Einheit kannst du …

  • Zielpräfix, Next Hop, Ausgangsinterface und Metrik eines Routingeintrags korrekt deuten
  • für eine Zieladresse den durch eine Routingtabellenzeile beschriebenen nächsten Weiterleitungsschritt bestimmen

1Einstieg: Was sagt eine Zeile aus?

Eine Route lautet `10.40.0.0/16 via 192.0.2.2 dev eth1`. Welche Aussage ist korrekt?

Nächster Schritt

Eine Route beschreibt nicht den vollständigen Pfad. Sie legt fest, wie der betrachtete Router das Paket als Nächstes weitergibt.

2Felder und Netzzugehörigkeit

Das Zielpräfix kombiniert Netzadresse und Präfixlänge. 10.40.0.0/16 umfasst alle Adressen, deren erste 16 Bit dem Netz entsprechen. Der Next Hop ist ein unmittelbar erreichbarer Nachbarrouter. Das Ausgangsinterface ist eine lokale Schnittstelle des aktuellen Routers. Bei einem direkt angeschlossenen Zielnetz kann die Tabelle statt eines Next Hops sinngemäß lokal oder connected anzeigen.

Eine Metrik bewertet Routen innerhalb eines Routingverfahrens. Ihre genaue Bedeutung ist nicht universell: Je nach Protokoll oder System kann sie beispielsweise Hops oder zusammengesetzte Kosten ausdrücken. Auch Ursprung und Präferenz einer Route können separat angezeigt werden; diese Entscheidungsebene folgt in einer späteren Einheit.

3Durchgearbeitetes Beispiel

Router R1 besitzt drei Einträge:

Zielpräfix Next Hop Interface Bedeutung
192.168.10.0/24 lokal lan0 direkt angeschlossenes Büronetz
172.20.0.0/16 10.0.0.2 transit0 an Nachbarrouter R2 übergeben
0.0.0.0/0 10.0.0.254 transit0 Fallback für sonstige IPv4-Ziele

Für 172.20.8.15 gilt die zweite Zeile. R1 sendet das Paket nicht direkt an den Zielhost, sondern über transit0 an R2 mit der Adresse 10.0.0.2. Für einen Host im eigenen Büronetz ist kein Router als Next Hop nötig.

Eine Tabellenzeile systematisch lesen

Bringe die Prüfschritte für ein eingehendes IP-Paket in eine belastbare Reihenfolge.

Geführte Übung
  1. 1Ermitteln, ob ein Next Hop benötigt wird oder das Ziel direkt verbunden ist.
  2. 2Die Ziel-IP aus dem Paket lesen.
  3. 3Alle Routingzeilen bestimmen, deren Präfix das Ziel einschließt.
  4. 4Das in der gewählten Zeile angegebene Ausgangsinterface verwenden.
  5. 5Aus den Kandidaten die beste Route auswählen.

0 Zeichen notiert
Muster: Das Zielpräfix bestimmt den Adressbereich der Route. Der Next Hop ist der unmittelbar nächste Router, das Ausgangsinterface die lokale Schnittstelle dorthin. Eine Metrik bewertet Routen innerhalb eines Verfahrens. Bei einem direkt angeschlossenen Netz entfällt ein weiterer Router; die Zustellung erfolgt über das lokale Interface.
